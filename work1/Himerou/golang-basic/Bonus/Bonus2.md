# Go语言中的切片和数组的区别

 1.  数组长度固定，切片长度可变

2. 数组创建要明确容量，切片可以不写

 3. 数组是值传递，切片是指针传递

4. 相同数据类型不同len的数组类型不同，而相同数据类型不同len的切片类型相同,也就是长度是数组的属性，而不是切片的属性



# Go创建切片的方法

## 1 .var声明

```go 
var S []int
```

## 2 .使用make函数 （必须带上长度len，容量capacity可不写)

```go
S :=make([]int,len)
```

## 3. 字面量 

```go
s:=[]int{}
```

## 4. 截取

```go
s1 :=[]int{1,2,3}
s2 :=s1[1:2]
```



# Go创建map的方法

## 1. 字面量创建

```go
m :=map[string]int{}
```

## 2.make函数

```go
m:=make(map[string]int，capacity)
```
