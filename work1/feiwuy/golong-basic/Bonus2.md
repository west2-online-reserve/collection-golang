# 切片和数组的区别:
1. **切片可变长而数组不可变长**
>数组是固定长度元素组成的序列,在声明时长度就已经定好不可再改变
>切片是一个由一个数组指针,len,capacity组成的结构体(struct),其中数组指针指向的空间大小为capacity.当切片元素数量大于最大容量时,编译器会自动在堆上开辟一个长度大于当前最大容量的内存空间并返回新的slice地址
2. **切片存储一个数组的指针而数组不是一个指针**
>与C不同,Go中数组不是一个指向某内存区域的指针.再调用时,会将整个数组元素拷贝一份
>Go中切片包含了一个数组的指针,在调用时只将对应切片的指针拷贝
3. **切片不需要提前设置长度而数组需要**
4. **数组的长度是其类型的一部分而数组不是**

# 创建切片方法:
1. var slice []int
2. slice := make([]int, len, capacity(可选))
3. slice := []int{1, 2, 3}
4. newSlice := slice[0:3]

# 创建map方法:
1. var m map[string]int
2. var m = map[string]int{"a":1, "b":2, "c":3}
3. var m = make(map[string]int, capacity(可选))
